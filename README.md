# Minlaucher

Your world. Your rules.

Minlaucher is a lightweight Minecraft: Java Edition launcher with Fabric support. Pick a version, optionally enable Fabric, set how much RAM the game gets, and launch. No ads, no telemetry.

## Features

- **Microsoft account sign-in** using the official Microsoft / Xbox / Minecraft Services authentication flow (public client, no client secret, passwords are never seen or stored)
- **Offline mode** with a custom nickname, for local testing
- **Version selection** with any Minecraft version and a button to refresh the version list
- **Fabric support** enabled with a single checkbox
- **RAM allocation slider** with a safe limit calculated from the system's total and currently available memory
- **Clean dark interface** with a minimal, distraction-free layout
